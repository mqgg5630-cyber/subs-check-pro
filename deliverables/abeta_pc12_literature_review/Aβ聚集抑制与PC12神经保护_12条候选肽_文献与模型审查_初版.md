# Aβ 聚集抑制与 PC12 神经保护：12 条候选肽筛选的文献与计算模型审查（初版）

**版本**：2026-10-14（Asia/Shanghai）<br>
**适用范围**：12 条候选肽的 Aβ 聚集抑制 / Aβ 毒性缓解 / PC12 神经保护筛选。
**重要限制**：用户指定的 `从12条肽筛选Aβ聚集与PC12实验.docx` 尚未同步到当前工作区。因此，本文件是按文件名所指的研究问题做的**文献与方法学审查**，并不把任何结论冒充为对那 12 条真实序列、修饰、浓度或既定 protocol 的特异性判断。收到文档（或序列表）后，才能做逐条肽映射、候选优先级和计算输入表。

## 一页结论

1. **已有很直接的“肽筛选 → Aβ 抑制 → PC12 保护”先例。**Gautam 等从肽库/体外进化中获得抑制 Aβ42 聚集的肽，用 ThT、AFM 与 PC12 挽救验证；Wu 等的 YVRHLKYVRHLK 采用对接、ThT 与 PC12 CCK-8；Mallesh 等还将 ThT/Congo red、CD/FTIR、EM、PC12 分化神经元、凋亡等串起来。因此，12 条肽小面板完全可以按“先快速筛、再正交确认、最后细胞验证”的结构开展，而不是只做一次 ThT。
2. **ThT 下降不是“神经保护已被证明”。**候选肽可自聚集、吸收/淬灭 ThT，或把 Aβ 导向另一种低 ThT 的聚集态；而毒性又强烈依赖 Aβ 的单体/寡聚体/纤维状态。因而需要候选肽单独对照、ThT 干扰对照，以及至少一项正交结构/形貌读出，再进入 PC12。
3. **MTT/CCK-8 单独不能等同于不可逆细胞死亡。**经典 PC12 工作表明 Aβ 可较早、可逆地影响 MTT 还原这一氧化还原读出；因此建议至少增加形态、膜完整性/LDH、凋亡或 ROS 中的一项正交细胞终点。
4. **MD 有价值，但不是“计算出一个 ΔG 就能宣布抑制剂”。**Aβ 是高度动态的 IDP/聚集体系。合理用途是解释候选肽可能遮挡的 Aβ 区段、比较多个 Aβ 构象/寡聚体上的接触稳定性、发现不理想的自聚集风险；其结论应以重复轨迹、多个结构模型和实验回证为条件。
5. **没有一款现成 DL/ML 模型已被充分验证，可直接为任意 12 条短肽输出“同时抑制 Aβ42 聚集并挽救 PC12”的可信排序。**现有模型主要预测的是候选肽自身的 amyloidogenicity/aggregation-prone regions（APR），而非 Aβ 结合、抑制动力学、Aβ 毒性物种，或 PC12 细胞救援。它们适合做**预筛/负向过滤/特征解释**，不应替代实验。
6. **最可操作的计算-实验路线**：先用 PALM / AggBERT / AmyloGram / PATH 等对候选肽的自身聚集风险做共识预筛；再用 Aβ 多构象对接与多重复 MD 做“机制假设”；最后以 ThT + 正交结构/形貌 + PC12 复合终点评定。Han 等 2025 年的 Word2Vec → 对接 → MD → ThT 验证路线，是目前最接近“短肽小库 Aβ 抑制剂发现”的可借鉴模板，但并非 PC12 终点的现成预测器。

## 1. 先把问题拆成四个不可互相替代的标签

| 层级 | 需要回答的问题 | 可用读出 | 常见误判 |
|---|---|---|---|
| P：候选肽本身 | 肽是否可溶、是否自聚集、是否本身伤害 PC12 或干扰染料？ | 候选肽空白、ThT 空白、DLS/浊度/形貌、PC12 peptide-alone | 把“ThT 低”误当“肽本身安全/不聚集” |
| A：Aβ 聚集过程 | 候选肽是否改变 Aβ 的 lag、斜率、终点或聚集物形貌？ | ThT 动力学、CR、CD/FTIR、AFM/TEM/DLS | 把单一终点荧光降低视为抑制 |
| O：毒性 Aβ 物种 | 候选肽减少的是纤维、可溶寡聚体，还是仅改变了通路？ | SEC/Native PAGE/寡聚体抗体（如可得）、DLS、形貌、处理时间窗 | “纤维少”却可能保留/富集有毒寡聚体 |
| C：PC12 保护 | 候选肽是否在 Aβ 暴露下真正改善细胞状态？ | CCK-8/MTT + 形态/LDH/Annexin V/ROS/活死染 | 将代谢/氧化还原变化直接解释为存活率 |

**建议的因果主张层级**：

- **仅有 ThT**：只能说“在该条件、该读出下改变 ThT 信号”；
- **ThT + 结构/形貌**：可说“与 Aβ 聚集状态/β-sheet 形成变化一致”；
- **再有 PC12 多终点**：可说“在该体外体系中，与减轻 Aβ 相关细胞损伤一致”；
- **只有在候选肽单独对照、Aβ 状态定义、重复与盲法/随机化（如适用）均充分时**，才应讨论候选肽的比较优先级。

### 2.1 面向 12 条肽的建议实验矩阵（方法学框架，不替代已定 protocol）

**第一层：避免假阳性 / 假阴性**

- 每条候选肽单独加入 ThT 的空白：判断荧光、内滤、淬灭、吸附或自聚集干扰；
- 候选肽单独处理 PC12：先排除本身的代谢/膜毒性；
- Aβ-alone、vehicle、候选肽-alone、Aβ + 候选肽共孵育四类最小分组；若要区分预防/解聚，再将“先形成 Aβ 再加肽”和“先混合再老化”分开；
- 记录 Aβ 肽的批号、单体化策略、溶剂残留、浓度确认、预孵育时间/温度、是否离心/过滤；这些变量可改变 Aβ 的寡聚体比例与细胞毒性。

**第二层：Aβ 聚集与结构的正交确认**

- 把 ThT 做成时间曲线而不是只测一个终点，报告原始空白校正、候选肽干扰控制和曲线形态；
- 优先在可用条件下加 1–2 个正交读出：CD 或 FTIR（β-sheet / random coil 趋势）、TEM/AFM（纤维/无定形/短纤维形貌）、DLS/SEC（粒径或可溶组分）；
- 若核心主张是“降低 Aβ 神经毒性”，优先问“是否减少有毒寡聚体”，不能只以成熟纤维为唯一目标。

**第三层：PC12 保护不只测一条代谢曲线**

- 用 CCK-8 或 MTT 作为敏感首筛，但配合形态/细胞数、LDH/膜完整性、Annexin V / caspase、ROS 或线粒体读出中的至少一个；
- 明确 PC12 是未分化还是 NGF 分化：两种状态对形态、受体/代谢和 Aβ 响应不同，不能直接把结果合并；
- 事先定义“候选肽改善”是否必须同时满足：候选肽-alone 无显著伤害、Aβ 聚集/毒性相关读出改变、PC12 至少两个终点同向；
- 引入具有文献基础的正控（例如 KLVFF、LPFFD，或实验室已有阳性肽）但不把不同实验条件下的文献效果当作本体系的定量基准。

## 3. 分子动力学 / 结构计算：什么真正有用，什么不能过度解释

### 3.1 推荐的 MD 问题表述（优先级由实验目标决定）

1. **如果首要目标是阻断成核/早期聚集**：不要只对一个“静态 Aβ 单体晶体结构”对接。以多个单体/小寡聚构象为集合，观察候选肽是否反复遮挡关键自识别区域，是否诱导局部 β-sheet / 疏水接触减少，以及候选肽本身是否形成稳定同源聚集。
2. **如果首要目标是降低毒性寡聚体**：选择有文献/实验支持的 Aβ1–42 寡聚模型，重点分析肽是否稳定非毒性构象、改变暴露疏水面、或改变膜相关表面；这比“对成熟纤维的 docking score”更贴近 PC12 问题。
3. **如果首要目标是解聚成熟纤维**：纤维端、沟槽或界面模型可以提出机制，但要把“阻止新生长”“表面吸附”“真正解聚”分开实验验证。
4. **统一原则**：每个候选肽至少在多个独立 MD 重复中报告接触占有率、二级结构、团簇/溶剂暴露、关键残基接触图及不确定性；避免只展示一条“最好看的轨迹”。

### 3.2 不能从 MD 直接推出的结论

- 不能仅凭 docking score / MM-PBSA 宣布 “抑制最强”；
- 不能从 Aβ 单体模型直接推出 PC12 救援；
- 不能把 Aβ16–22 或 Aβ1–40 片段的机制，无条件外推到 Aβ1–42 寡聚体；
- 不能忽略候选肽的末端状态、D/L 构型、环化、脂化、盐、pH、离子强度和浓度比；这些可能改变动力学与相互作用。

## 4. 深度学习 / 机器学习模型盘点

### 4.1 结论先行：现有模型到底预测什么？

下表中的绝大多数工具预测的是**候选肽自身**是否具有 amyloidogenicity / aggregation-prone region，而不是“它能否抑制另一条 Aβ 肽”。这两类任务方向甚至可能相反：一个候选肽自身很容易聚集，可能带来溶解性和干扰问题；但低自身聚集风险并不自动说明它会结合、遮挡或重定向 Aβ。

| 模型 / 文献 | 类型与训练任务 | 对本项目最合适的用途 | 不能声称什么 | 获取性 / 备注 |
|---|---|---|---|---|
| **PALM**（Eschbach et al., 2026，DOI [10.1021/acs.jcim.6c00577](https://doi.org/10.1021/acs.jcim.6c00577)） | ESM2 embedding + light-attention；sequence-level 聚集与 residue-level APR。 | 对 12 条候选肽做**自身聚集风险 / APR 位置**预筛；适合序列长度不止 6 aa 的场景。 | 不预测 Aβ 抑制、PC12 保护或真实结合亲和力。论文还报告基础模型对 Aβ 单点致聚突变不佳，需更大数据训练才改善。 | [GitHub: novonordisk-research/PALM](https://github.com/novonordisk-research/PALM)；本组目前最值得优先试的开源深度模型之一。 |
| **AggBERT**（Perez et al., 2023，DOI [10.1021/acs.jcim.3c00817](https://doi.org/10.1021/acs.jcim.3c00817)） | fine-tuned ProtBERT + 半监督；以 WALTZ-DB 2.0 的**hexapeptide** amyloidogenicity 为主。 | 若 12 条肽为 6 aa，或可滑窗成 6-mer，用作自身 amyloid propensity 共识分数。 | 不是 Aβ 结合/抑制模型；训练域对长度和数据分布敏感。 | 论文的半监督模型在其 hexapeptide benchmark 上表现强，但不可把内部 benchmark 当作 PC12 预测性能。 |
| **AggNet**（He et al., 2025，DOI [10.1002/pro.70031](https://doi.org/10.1002/pro.70031)） | ESM2 + AAindex；同时建模 peptide amyloid/non-amyloid 与蛋白 APR（结构通道用 AlphaFold2）。 | 作为另一个 APR / 自聚集解释器；适合和 PALM 做一致/冲突检查。 | AlphaFold2 对高度无序短肽/Aβ 复合物的可信度有限；非 Aβ inhibitor 训练标签。 | 论文报告开源代码；工具的表现应在你的肽长度和改造类型上复核。 |
| **CANYA**（Thompson et al., 2025，DOI [10.1126/sciadv.adt5111](https://doi.org/10.1126/sciadv.adt5111)） | >100,000 随机序列聚集测定训练的 convolution-attention 网络。 | 可作为大规模、相对宽分布的“候选肽自身聚集风险”背景模型。 | 数据任务仍是 intrinsic aggregation；随机序列语境不等于药理性 Aβ 抑制。 | 重要价值在于显示许多旧模型在更宽序列空间的表现有限，因此需要校准期望。 |
| **PATH**（Wojciechowski & Kotulska, 2020，DOI [10.1038/s41598-020-64270-3](https://doi.org/10.1038/s41598-020-64270-3)） | amyloid structural classes threading + ML；主攻 hexapeptide。 | 作为 6-mer 结构相容性/自身纤维风险的互补特征。 | 不预测 Aβ42 毒性、细胞毒性或相互作用。 | [GitHub: KubaWojciechowski/PATH](https://github.com/KubaWojciechowski/PATH)。 |
| **AmyloGram**（Burdukiewicz et al., 2017，DOI [10.1038/s41598-017-13210-9](https://doi.org/10.1038/s41598-017-13210-9)） | n-gram + random forest；6–15 aa 热点/amyloidogenicity。 | 轻量的、可解释的 ML 共识评分；可输出局部 motif 风险。 | 不代表“低分就能抑制 Aβ”。 | R package 可用；适合与深度模型组成共识而非单独决策。 |
| **APPNN**（Família et al., 2015，DOI [10.1371/journal.pone.0134679](https://doi.org/10.1371/journal.pone.0134679)） | 理化/生化特征 + feed-forward NN。 | 传统 ANN 基线；可解释为什么 pI、疏水性、β-sheet 倾向同时影响风险。 | 文中外部验证准确率不代表你的 12 条修饰肽或 Aβ 抑制能力。 | R package `appnn`。 |
| **TANGO / PASTA 2.0 / WALTZ-DB 2.0** | 物理/经验/数据库基线，不是最新 DL。 | 快速 sanity check、查看 β-pairing / hotspot，或校验 hexapeptide 是否离开已知数据域。 | 不能作为最终优先级单一裁判。 | TANGO: DOI [10.1038/nbt1012](https://doi.org/10.1038/nbt1012)；PASTA: DOI [10.1093/nar/gku399](https://doi.org/10.1093/nar/gku399)；WALTZ-DB 2.0: DOI [10.1093/nar/gkz758](https://doi.org/10.1093/nar/gkz758)。 |
| **Han 2025 workflow** | Word2Vec → docking → MD → ThT，是发现工作流而非一个“端到端预测器”。 | 最接近 12 条肽项目的实际执行范式；可把模型作为候选生成/相似性特征，而不是结论机。 | 没有用“PC12 rescue”标签训练，也没有证明可泛化到任何序列。 | 推荐作为 pipeline 参考而非直接下载即用的打分器。 |

### 4.2 建议如何使用模型，而不是被模型误导

**推荐：用“共识 + 不确定性”做预筛，而不是用一个黑盒分数定胜负。**

1. 每条肽记录长度、净电荷、疏水性、Pro/Gly/芳香残基、预计 pI、修饰和末端状态；
2. 对未修饰天然序列用 2–4 个自身聚集模型（例如 PALM + AggBERT/PATH〔适用时〕+ AmyloGram + 一个物理基线）；
3. 只将结果作为“自聚集 / 可溶性风险旗标”：高一致风险、模型强烈冲突、或序列落在训练域外时，优先实验检查，而不是武断剔除；
4. 将 Aβ 对接/MD 输出限制为机制假设：**多构象接触的一致性、关键区域遮挡、候选肽自聚集倾向**；
5. 用实验数据反哺：当 12 条肽的 ThT、形貌和 PC12 数据到手，可做小样本、带不确定性的探索性关联；12 条本身远不足以训练可靠 DL 模型。

### 4.3 一个可落地的“三级优先级”定义

- **A 组（先做/先复验）**：候选肽-alone 不显示明显问题；多个自聚集模型未出现一致高风险；在不止一个 Aβ 构象上出现稳定且可解释的接触模式；实验中至少出现 ThT 和一个正交结构读出的相同方向信号。
- **B 组（平行确认）**：模型互相冲突、或只有单一读出支持；不淘汰，但优先补充候选肽干扰/形貌/毒性对照。
- **C 组（需先排风险）**：候选肽自身明显聚集、强烈影响染料、PC12-alone 可见伤害、或 MD 反复显示候选肽自聚集/对 Aβ 无稳定机制。C 组不是“无效”的同义词，但不应被直接解释为 Aβ 抑制剂。

在附件/下次消息中请提供下列最少信息，才能做序列特异性评审：

|---|---|
