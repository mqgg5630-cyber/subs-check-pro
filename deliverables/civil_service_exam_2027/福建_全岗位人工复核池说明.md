# 福建全岗位人工复核池（按“不以专业自动排除”扩展）

> 这是按“福建优先、即使专业文字不匹配也先给我看”的要求生成的**人工核验池**，不是可报岗位名单，更不是录取概率或推荐排名。

## 这次扩展做了什么

- 覆盖工作地点含“福建”的全部 **686** 条职位表行；福州、厦门、泉州、漳州等城市别名复核后没有遗漏额外行。
- 不再因“专业”栏与私有专业关键词没有文字匹配而从文件中删除岗位。
- 仍然保留并标识学历、学位、政治面貌、基层经历、服务项目、外语、性别、户籍/生源和应届身份等**非专业**条件的机械核验结果。
- 不导出个人 profile、个人字段值或带有个人字段值的解释文本；只输出公共职位表字段、源定位和“有无冲突/需复核”的字段名。

## 文件说明

| 文件 | 行数 | 用途 |
|---|---:|---|
| [`福建_全岗位人工复核池.csv`](福建_全岗位人工复核池.csv) | 686 | 福建全部职位表行，包含有明确冲突的岗位，适合完整查阅。 |
| [`福建_非专业无明确冲突_复核队列.csv`](福建_非专业无明确冲突_复核队列.csv) | 426 | 已剔除存在**非专业**机械冲突的 260 行；仍可能有专业不匹配或其他备注条件，不可直接报名。 |

全池的分类计数：

| 人工复核分类 | 行数 | 含义 |
|---|---:|---|
| A：非专业条件未见机械冲突 | 319 | 已解析的非专业字段未发现冲突；仍须确认专业及备注。 |
| B：非专业条件需人工核验 | 107 | 没有明确冲突，但学历、学位或其他已解析字段的表述需要人工确认。 |
| C：非专业条件有明确冲突 | 260 | 至少一项已解析的非专业条件与私有条件冲突；保留仅供完整查阅。 |

专业文字比对结果：2 行直接文字匹配、684 行未直接匹配。前述“文字未匹配”不等于官方最终否定，但也**绝不等于**“不限专业”。

## 如何使用 CSV

1. 优先从 `福建_非专业无明确冲突_复核队列.csv` 开始，而不是从全部 686 行开始。
2. 查看 `专业文字比对`：
   - `专业文字直接匹配`：仍须拿毕业证、学位证和目录复核；
   - `专业关系需按官方目录人工确认`：联系招录机关或查目录；
   - `专业文字未匹配；仅因要求查看全池而保留`：不应自行当作可报。
3. 查看 `非专业明确冲突字段` 和 `非专业需人工核验字段`，再回到同一行的公共条件和 `备注（原文）`。
4. `备注提示` 只是提醒词，不是完整资格判断。凡出现资格/证书、体检/体能、服务期、专项/定向、户籍/生源、工作经历或专业能力测试，都要读完整备注。
5. 使用 `来源工作表` 与 `Excel行号` 回到原始 XLS 复核。同一职位代码可能在不同机关重复，不能只按代码定位。

## 关于“明确不限专业”

原工作簿中，福建没有一条“专业”栏明确写作 `不限`、`专业不限`、`不限专业`、`无限制` 或 `不限制` 的岗位。本复核池是**放宽查看范围**，不是将这些福建岗位改写成“不限专业”。

因此，最终报名时仍须以职位表专业栏、报名系统校验和招录机关答复为准；如果专业不能对应，不能以本文件作为报考依据。

## 可复现方式

先在本机私有 profile 下生成标准化输出，再导出不含 profile 值的人工池：

```bash
python3 code/civil_service_exam/analyze_positions.py \
  --input 'results/civil_service_exam/source/中央机关及其直属机构2027年度考试录用公务员招考简章.xls' \
  --profile config/civil_service_profile.local.json \
  --out results/civil_service_exam/local_analysis

python3 code/civil_service_exam/export_manual_pool.py \
  --input results/civil_service_exam/local_analysis/all_positions_normalized.csv \
  --region 福建 \
  --out deliverables/civil_service_exam_2027/福建_全岗位人工复核池.csv

python3 code/civil_service_exam/export_manual_pool.py \
  --input results/civil_service_exam/local_analysis/all_positions_normalized.csv \
  --region 福建 \
  --exclude-non-major-mismatch \
  --out deliverables/civil_service_exam_2027/福建_非专业无明确冲突_复核队列.csv
```
