# 复核与排除说明

## 为什么福建只有一个条件性候选

福建工作地点的 686 条职位表行中，专业栏含“生物”的只有两条，均来自厦门海关东山海关：

| 职位代码 | 职位 | 表内专业中与本人背景直接相关的文字 | 结果 |
|---|---|---|---|
| `300110011001` | 动植物检疫一级行政执法员（一） | 生物科学 | 列入人工复核；备注限男性，但学历/学位为仅限本科/学士 |
| `300110011002` | 动植物检疫一级行政执法员（二） | 生物科学 | 排除；备注限女性，与私有自述条件冲突 |

第一条不是“已确认可报”：职位备注还写明专业按具体名称认定、须具备与填报学历及专业相应的学位，且是现场一线岗位、适用体检特殊标准、最低服务年限为 5 年。

## 为什么山东为空

- 在工作地点为山东的 1,223 条职位表行中，`专业`栏没有“生物”字样。
- 机械初筛也没有留下非“初筛不匹配”的山东行。
- 部分岗位名称或工作内容可能与检疫、食品、农业、化工等有交集，但职位表的专业栏在很多此类岗位明确列出具体名称；本轮不把“相近”推断为“符合”。

因此，山东清单没有职位行，而不是漏填或排名靠后。若本人另有能够直接对应表内专业名称的学历/学位，或招录机关确认专业目录可对应，再以该可核验证据重新筛选。

## 机械规则和人工规则的边界

机械脚本可处理：工作地点、职位表明示的性别、政治面貌、基层年限、服务基层项目、应届表述、CET-4/CET-6 阈值、学历/学位和专业文字的直接比对。

以下事项一律保留给人工确认，不能由分数或字符串匹配代替：

1. 专业名称、代码和目录对应关系；
2. 研究生是否可以用本科层次学历/学位报名“仅限本科/学士”职位；
3. 年龄截止日和应届身份的官方定义；
4. 体检特殊标准、岗位现场条件、最低服务期限；
5. 报名系统最终校验以及招录机关答复。

## 可复现运行

在已安装表格依赖且配置了本机私有 profile 的环境中：

```bash
python3 code/civil_service_exam/analyze_positions.py \
  --input 'results/civil_service_exam/source/中央机关及其直属机构2027年度考试录用公务员招考简章.xls' \
  --profile config/civil_service_profile.local.json \
  --out results/civil_service_exam/local_analysis
```

该输出目录和 profile 均被 Git 忽略；本交付物只保留公共职位表中的必要字段、源定位和复核结论。解析器会读取工作簿中所有识别到职位表头的工作表，而不是只选第一个工作表。
