## 本轮筛选口径

仅使用本人已提供的私有资格与偏好作核验，不从姓名、地域等信息推断任何身份。交付物不复制本机 profile；这里仅保留完成复核所必需的结论：以生物学相关学历背景为专业起点，按福建优先、山东备选的顺序检查学历/学位、应届、英语、性别、政治面貌、基层经历和服务项目等职位表条件。

专业采用**保守的文字口径**：

1. 先要求职位“专业”栏出现与生物学背景直接相关的文字，不把化学、食品、农业、医学或检验检疫等相邻领域自动等同为生物学；
2. 职位表写明“本职位所指专业为具体专业名称”时，必须以毕业证、学位证和官方专业目录逐字确认；
3. “仅限本科/学士”不被脚本在存在更高学历信息时自动放行，而是单列为人工复核阻断项。

完整机械初筛由 [`code/civil_service_exam/analyze_positions.py`](../../code/civil_service_exam/analyze_positions.py) 完成；个人 profile 与全量个人化输出保持在 Git 忽略路径，未放入本交付物。

## 报名前必须完成的复核

1. 在报名系统确认可否以自己的本科层次学历/学位报考该福建岗位，并确认毕业证专业名称能否对应职位所列“生物科学”；不能只因目前还有更高学历而自行假定可或不可。
2. 对照毕业证、学位证、官方专业目录和职位备注中的“具体专业名称”要求。
3. 核验年龄截止日期、2027 应届身份认定、英语成绩证明、体检特殊标准、现场一线工作要求和最低服务年限。
4. 如仍有专业或学历层次疑问，以职位表所列咨询电话/招录机关书面或可留痕答复为准。

> 结论的“空山东清单”是一个有效筛选结果，不应用相邻专业或未经证实的目录对应关系填充成看似可报的岗位。
