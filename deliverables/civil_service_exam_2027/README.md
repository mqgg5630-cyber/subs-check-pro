# 2027 国考职位表：可复核筛选交付物

所有结果均来自 `中央机关及其直属机构2027年度考试录用公务员招考简章.xls`，并保留来源工作表和 Excel 行号以便复核。它们不是官方资格审查、录取概率、竞争度或待遇预测；最终以报名系统、职位表原文、专业目录和招录机关答复为准。

## 一、严格“明确不限专业”：福建优先、山东备选

本口径只接受职位表 `专业` 栏**完整写作**以下之一的岗位：`不限`、`专业不限`、`不限专业`、`无限制`、`不限制`、`无要求`。不把相近专业、长专业列表，或“本科不限、研究生另有限制”的职位混入。

**结果：福建 0 条，山东 0 条。**

- [`严格不限专业_福建优先_山东备选.md`](严格不限专业_福建优先_山东备选.md)：扫描范围、严格定义与零结果审计。
- [`严格不限专业_福建优先_山东备选.csv`](严格不限专业_福建优先_山东备选.csv)：机器可读的地区结果。
- [`全国明确不限专业_8条_部门代码及完整职位号.csv`](全国明确不限专业_8条_部门代码及完整职位号.csv)：全国严格命中的 8 条；它们都不在福建/山东，且均有已知非专业硬性冲突，不能当作可报名单。

## 二、全国 19 条生物学文字匹配的机械初筛

在不同于“不限专业”的口径下，全表保留 19 条专业栏出现生物学相关文字、且已解析字段未见机械冲突的岗位。它们不是“不限专业”岗位，也不表示官方已确认可报。18 条有生物学/生物科学/相应类别的直接文字；另 1 条仅因“化学生物学”命中，必须按专业目录另行确认。

- [`全国_19条机械初筛岗位.csv`](全国_19条机械初筛岗位.csv)
- [`全国_19条机械初筛岗位说明.md`](全国_19条机械初筛岗位说明.md)

## 三、从 19 条中排出的优先复核 5 条

按专业文字匹配、学历层次、已知条件是否冲突，以及特殊体检/体能/轮班/服务期等额外复核负担排序；没有将其包装为录取概率。福建和山东在严格范围内均无结果，因此这 5 条都是异地备选。

- [`全国19条_优先复核5条.csv`](全国19条_优先复核5条.csv)：含部门代码、完整职位代码、原始专业/备注和来源定位。
- [`全国19条_优先复核5条说明.md`](全国19条_优先复核5条说明.md)：透明排序理由与逐条报名复核事项。
